# 星叶守望 Starleaf Wardens

一款在浏览器里运行的 3D 奇幻塔防游戏雏形。灵感来自 *Tower Dominion*：用地形块搭出高地、拉长敌人的路线，在高地上建塔，并不断向外开拓地图。

**▶ 在线试玩：https://hitanorain.github.io/starleaf-wardens/**

## 玩法

- **地形手牌**：每波获得各种形状的地形块（R 旋转），放下后覆盖的格子抬高一级。抬高的地块会挡住敌人，也是唯一能建塔的地方。
- **高地加成**：塔建在 2 级、3 级高地上，射程和伤害更高。
- **区域扩张**：每 2 波开拓一块新区域（开阔平地 / 岩石高地 / 地脉晶簇 / 水源 / 远古遗迹）。放在传送门一侧会把敌人的入口推远。
- **月之仙子露娜**：右键指挥她飞行作战。Q 星落（流星雨）、E 森之绽放（给附近的塔加攻速）。
- **森林祝福**：每波结束三选一，打造自己的流派。坚持 15 波，击败腐化巨魔王。
- **三张地图**：翠叶森林、黄沙峡谷、霜雪高原。

## 操作

| 按键 | 作用 |
|---|---|
| 点击地形块 → `R` 旋转 → 左键 | 放置地形块 |
| `Z` / `X` | 单格隆起 / 削低（消耗地脉能量） |
| `1`–`4` | 选择要建的塔 |
| 左键点塔 | 查看、升级 `U`、出售 `Del` |
| 右键 | 让露娜飞过去 / 取消当前工具 |
| `Q` / `E` | 露娜技能 |
| `空格` | 开始下一波 |
| `Ctrl+Z` | 撤销本次备战阶段的操作 |
| `WASD` / 中键拖动 / 滚轮 | 移动 / 缩放镜头 |
| `F` / `P` / `H` | 加速 / 暂停 / 帮助 |

## 本地运行

需要联网加载 three.js。任选一种方式：

```bash
python serve.py
```

然后打开 http://localhost:8765 。也可以直接双击 `index.html` 打开。

## 技术

- 纯 HTML + JavaScript，无需构建；3D 渲染使用 [three.js](https://threejs.org/) r128
- 场景、塔、怪物、角色全部由代码生成（低多边形 + 程序化地形）
- 后处理：泛光（Bloom）+ ACES 色调映射 + 暗角
- 界面图标、头像与标题画面由 ChatGPT 生成（需求见 [ART_REQUESTS.md](ART_REQUESTS.md)）
